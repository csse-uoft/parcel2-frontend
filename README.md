# Parcel2 Frontend

Parcel2 Frontend is a Next.js 15 App Router project that powers the Parcel2 console and marketing site. It uses Material UI for theming, React Hook Form for complex forms, and SWR for data fetching against the Parcel2 backend API.

## Prerequisites

- Node.js 20 LTS (or >= 18.18)
- npm 10+
- Running Parcel2 backend API (see `NEXT_PUBLIC_API_BASE` below)

## Quick Start

1. Install dependencies:
	```bash
	npm install
	```
2. Copy the environment template and update values if needed:
	```powershell
	Copy-Item .env.template .env.local
	```
	(macOS/Linux: `cp .env.template .env.local`)
3. Ensure `NEXT_PUBLIC_API_BASE` points to the backend URL that issues auth cookies.
4. Start the development server:
	```bash
	npm run dev
	```
5. Open `http://localhost:3106` in your browser.

## Environment Variables

- `NEXT_PUBLIC_API_BASE`: Base URL for the Parcel2 backend (default `http://localhost:3105`).

Environment files follow the standard Next.js naming conventions (`.env.local`, `.env.development`, etc.).

## npm Scripts

- `npm run dev` – run the development server with Turbopack.
- `npm run build` – compile the production build.
- `npm start` – serve the production build generated by `npm run build`.
- `npm run lint` – run ESLint using the Next.js configuration.

## Project Layout

- `src/app` – Next.js App Router pages and layouts.
- `src/components` – shared UI components (forms, console shell, uploads, etc.).
- `src/contexts` – React context providers for auth and drawer state.
- `src/lib` – fetch utilities, API hooks, and client helpers.
- `public` – static assets served by Next.js.

## Production Build

1. Build the app: `npm run build`
2. Start the server: `npm start`

This runs the compiled Next.js app using the `.env.production` (and `.env.local`) environment variables.

## Troubleshooting

- Ensure the backend issues a `token` cookie and supports the URL configured in `NEXT_PUBLIC_API_BASE`.
